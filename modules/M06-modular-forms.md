# M06 · 模形式（Modular Forms）

模方程与模函数。模形式是拉马努金全部工作的组织骨架：tau 函数、theta 函数、模方程都在这套语言里。

## 核心定义

Eisenstein 级数 $E_4, E_6$ 与判别式：

$$\Delta(\tau) = \frac{E_4(\tau)^3 - E_6(\tau)^2}{1728} = q \prod_{n=1}^{\infty} (1-q^n)^{24} = \sum_{n=1}^{\infty} \tau(n)\, q^n$$

其中 $q = e^{2\pi i \tau}$，$\tau(n)$ 为 Ramanujan tau 函数（见 M01）。

j-不变量：

$$j(\tau) = 1728\,\frac{E_4(\tau)^3}{E_4(\tau)^3 - E_6(\tau)^2}$$

## 代表内容

### 模方程

$n$ 次模方程是联系 $j(\tau)$ 与 $j(n\tau)$ 的代数关系 $\Phi_n(X, Y) = 0$。拉马努金给出 3 次、5 次、7 次等多个次数的模方程，这是他 1914 年 1/π 级数（见 M04）的推导来源。

### 奇异模

当 $K'/K = \sqrt{n}$（$n$ 为正整数）时，椭圆模 $k$ 的值称为奇异模，多表为根式与 Gamma 值之比（见 M11）。
