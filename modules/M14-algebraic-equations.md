# M14 · 代数方程（Algebraic Equations）

丢番图方程与代数关系。

## 代表公式

### Ramanujan–Nagell 方程

$$x^2 + 7 = 2^n$$

整数解只有 $n = 3, 4, 5, 7, 15$（对应 $x = \pm 1, \pm 3, \pm 5, \pm 11, \pm 181$）。拉马努金猜想这就是全部解，1948 年由 Nagell 证明。

### 1729：两个立方和的两种表示

$$1729 = 1^3 + 12^3 = 9^3 + 10^3$$

这是最小的能用两种方式表为两个正立方和的数（出租车数 Taxicab(2)）。典故：1918 年哈代去医院看病时说出租车号 1729 平淡无奇，拉马努金当即指出这个性质。
