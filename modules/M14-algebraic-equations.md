# M14 · 代数方程（Algebraic Equations）

丢番图方程与代数关系。本模块已从拉马努金专章扩展为**通用代数方程库**：从求根公式到 Vieta 定理、有理根定理、丢番图方程与特殊恒等式一并收录。

## M14.1 求根公式

### 二次方程

$$x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}, \qquad \Delta = b^2 - 4ac$$

### 三次方程（Cardano 公式）

$x^3 + px + q = 0$ 的根：

$$x = \sqrt[3]{-\frac{q}{2} + \sqrt{\left(\frac{q}{2}\right)^2 + \left(\frac{p}{3}\right)^3}} + \sqrt[3]{-\frac{q}{2} - \sqrt{\left(\frac{q}{2}\right)^2 + \left(\frac{p}{3}\right)^3}}$$

### 四次方程与五次以上

四次方程有根式解（Ferrari，1540），经预解三次方程化归；五次及以上一般没有根式解（Abel–Ruffini 定理，1824），由 Galois 理论判定可解性。

## M14.2 Vieta 定理

### 二次方程

$$x_1 + x_2 = -\frac{b}{a}, \qquad x_1 x_2 = \frac{c}{a}$$

### 三次方程

$x^3 + ax^2 + bx + c = 0$ 的三根：

$$x_1 + x_2 + x_3 = -a, \qquad x_1x_2 + x_1x_3 + x_2x_3 = b, \qquad x_1x_2x_3 = -c$$

### 一般形式

$a_nx^n + a_{n-1}x^{n-1} + \cdots + a_0 = 0$ 的根 $r_1, \dots, r_n$ 满足：

$$e_k(r_1, \dots, r_n) = (-1)^k \frac{a_{n-k}}{a_n}$$

其中 $e_k$ 为第 $k$ 个初等对称多项式。

## M14.3 有理根定理

整系数多项式 $a_nx^n + \cdots + a_1x + a_0 = 0$ 的有理根 $p/q$（既约）满足 $p \mid a_0$ 且 $q \mid a_n$；特别地，首一整系数多项式的有理根必为整数，且整除常数项 $a_0$。

## M14.4 丢番图方程

### 线性丢番图方程

$ax + by = c$ 有整数解当且仅当 $\gcd(a, b) \mid c$。

### 勾股数

$x^2 + y^2 = z^2$ 的本原解：

$$x = m^2 - n^2, \qquad y = 2mn, \qquad z = m^2 + n^2$$

其中 $m > n$ 互素且一奇一偶。

### Pell 方程（见 M03.6）

$x^2 - Dy^2 = 1$（$D$ 非平方数）有无穷多整数解，全部由最小解 $(x_1, y_1)$ 生成：

$$x_k + y_k\sqrt{D} = (x_1 + y_1\sqrt{D})^k$$

### 费马大定理（见 M01.5）

$x^n + y^n = z^n$ 在 $n \ge 3$ 时无正整数解（Wiles，1994–1995）。

## M14.5 特殊方程与恒等式

### Ramanujan–Nagell 方程

$$x^2 + 7 = 2^n$$

整数解只有 $n = 3, 4, 5, 7, 15$（对应 $x = \pm 1, \pm 3, \pm 5, \pm 11, \pm 181$）。拉马努金猜想这就是全部解，1948 年由 Nagell 证明。

### 1729：两个立方和的两种表示

$$1729 = 1^3 + 12^3 = 9^3 + 10^3$$

这是最小的能用两种方式表为两个正立方和的数（出租车数 Taxicab(2)）。典故：1918 年哈代去医院看病时说出租车号 1729 平淡无奇，拉马努金当即指出这个性质。

### 三立方和问题

$x^3 + y^3 + z^3 = k$：$k = 33$ 与 $k = 42$ 的解于 2019 年找到；$k \equiv \pm 4 \pmod 9$ 的情形无解。
