# M11 · 椭圆函数（Elliptic Functions）

椭圆积分与椭圆模数。拉马努金的模方程理论是他最具独创性的工作之一，1914 年的 1/π 级数就源于这套理论。

## 核心定义

第一类完全椭圆积分：

$$K(k) = \int_0^{\pi/2} \frac{d\theta}{\sqrt{1 - k^2 \sin^2\theta}}$$

其中 $k$ 为模数，$k' = \sqrt{1-k^2}$ 为余模数；nome $q = e^{-\pi K'/K}$ 把椭圆积分与 theta 函数、模形式连在一起。

## 代表公式

### 拉马努金的 1/π 级数（1914）

$$\frac{1}{\pi} = \frac{2\sqrt{2}}{9801} \sum_{n=0}^{\infty} \frac{(4n)!\,(1103 + 26390n)}{(n!)^4\, 396^{4n}}$$

该级数每项约给出 8 位十进制精度，源于模方程与奇异模的理论。完整推导与更多 1/π 级数见《数学全景图》拉马努金卷 r4。

## 来源与延伸

- 出处：三本笔记中的模方程条目；失落笔记约三分之一关于模方程与奇异模。
- 拉马努金给出 3 次、5 次、7 次等多个次数的模方程；奇异模指 $K'/K = \sqrt{n}$（$n$ 为正整数）时的模数值，多表为根式与 Gamma 值之比。
