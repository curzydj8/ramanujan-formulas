# M03 · 连分数（Continued Fractions）

拉马努金连分数与通用连分数公式库。本模块已从拉马努金专章扩展为**通用连分数公式库**：基本理论、著名常数、最佳逼近、Pell 方程，欧拉、拉格朗日、Lambert、Brouncker、高斯、拉马努金等人的工作一并收录。拉马努金本人的连分数工作集中在 M03.4 与 M03.7。

## M03.1 基本概念与渐近分数

### 一般连分数记法

$$b_0 + \frac{a_1}{b_1 + \frac{a_2}{b_2 + \frac{a_3}{b_3 + \cdots}}}$$

简单连分数（全部 $a_i = 1$）记作 $[b_0; b_1, b_2, \dots]$。有理数的简单连分数有限，无理数的无限。

### 渐近分数的递推公式

设 $p_n/q_n$ 为 $[b_0; b_1, \dots, b_n]$ 的值，则

$$p_n = b_n p_{n-1} + p_{n-2}, \qquad q_n = b_n q_{n-1} + q_{n-2}$$

初值 $p_{-2} = 0$、$p_{-1} = 1$、$q_{-2} = 1$、$q_{-1} = 0$。

### 行列式恒等式

$$p_n q_{n-1} - p_{n-1} q_n = (-1)^{n-1}$$

由此 $p_n/q_n$ 恒为既约分数，且相邻两项渐近分数分居 $x$ 两侧。

### 逼近误差

$$\left|x - \frac{p_n}{q_n}\right| < \frac{1}{q_n q_{n+1}}$$

渐近分数是「最佳逼近」：任何分母不超过 $q_n$ 的分数都不比 $p_n/q_n$ 更接近 $x$。

### Lagrange 定理

一个实数的简单连分数最终循环，当且仅当它是二次无理数（如 $\sqrt{2}$、黄金比）。

## M03.2 著名常数的连分数

### 黄金比（最慢收敛的连分数）

$$\varphi = \frac{1 + \sqrt{5}}{2} = [1; 1, 1, 1, \dots]$$

全部偏商都是 1，收敛最慢；这是 Hurwitz 常数 $\sqrt{5}$ 取到最优的原因（见 M03.3）。

### $\sqrt{2}$（周期连分数）

$$\sqrt{2} = [1; \overline{2}] = [1; 2, 2, 2, \dots]$$

渐近分数 $1/1$、$3/2$、$7/5$、$17/12$、$41/29$、$99/70$、$\dots$（见 M03.6 的 Pell 方程）。

### $\sqrt{3}$ 与 $\sqrt{5}$

$$\sqrt{3} = [1; \overline{1, 2}], \qquad \sqrt{5} = [2; \overline{4}]$$

### $e$（Euler，1737）

$$e = [2; 1, 2, 1, 1, 4, 1, 1, 6, 1, 1, 8, \dots]$$

偏商呈现规律 $1, 2k, 1$（$k = 1, 2, 3, \dots$）。Euler 由此证明了 $e$ 的无理性。

### $\pi$（无已知规律）

$$\pi = [3; 7, 15, 1, 292, 1, 1, 1, 2, 1, 3, 1, \dots]$$

其中大偏商 $292$ 使渐近分数 $355/113$ 异常精确：$|\pi - 355/113| < 3 \times 10^{-7}$。

## M03.3 最佳逼近定理

### Dirichlet 逼近定理（Dirichlet，1842）

对任意无理数 $x$，有无穷多组互素整数 $p, q$ 满足：

$$\left|x - \frac{p}{q}\right| < \frac{1}{q^2}$$

### Legendre 定理

若 $\left|x - p/q\right| < 1/(2q^2)$，则 $p/q$ 必为 $x$ 的渐近分数。

### Hurwitz 定理（Hurwitz，1891）

对任意无理数 $x$，有无穷多组 $p, q$ 满足：

$$\left|x - \frac{p}{q}\right| < \frac{1}{\sqrt{5}\, q^2}$$

常数 $\sqrt{5}$ 是最优的：对黄金比 $\varphi$，任何更小的常数都只对有限多组 $p, q$ 成立。

## M03.4 Rogers–Ramanujan 连分数

$$R(q) = \frac{q^{1/5}}{1 + \frac{q}{1 + \frac{q^2}{1 + \frac{q^3}{1 + \cdots}}}}$$

它满足恒等式（$|q| < 1$）：

$$R(q) = q^{1/5}\,\frac{(q;q^5)_\infty\,(q^4;q^5)_\infty}{(q^2;q^5)_\infty\,(q^3;q^5)_\infty}$$

其中 $(a;q)_\infty$ 为 q-Pochhammer 符号（见 M07）。该连分数与 Rogers–Ramanujan 恒等式（M07）本质上是同一组事实的两种面孔。

## M03.5 其他著名连分数

### Brouncker 公式（Brouncker，1655）

$$\frac{4}{\pi} = 1 + \frac{1^2}{2 + \frac{3^2}{2 + \frac{5^2}{2 + \cdots}}}$$

历史上第一个关于 $\pi$ 的广义连分数。

### Lambert 正切连分数（Lambert，1761）

$$\tan x = \frac{x}{1 - \frac{x^2}{3 - \frac{x^2}{5 - \frac{x^2}{7 - \cdots}}}}$$

Lambert 由此证明了 $\pi$ 的无理性：若 $x$ 为非零有理数，则 $\tan x$ 为无理数；而 $\tan(\pi/4) = 1$ 有理，故 $\pi/4$ 从而 $\pi$ 为无理数。

### Gauss 超几何连分数（Gauss，1812）

超几何函数之比可用连分数表示，例如

$$\frac{{}_2F_1(a, b+1; c+1; z)}{{}_2F_1(a, b; c; z)}$$

的连分数展开。Gauss 的连分数理论是现代特殊函数连分数的源头。

## M03.6 连分数与 Pell 方程

Pell 方程 $x^2 - Dy^2 = 1$（$D$ 为非平方正整数）的基本解由 $\sqrt{D}$ 的渐近分数给出：设 $\sqrt{D}$ 的连分数周期长为 $r$，$r$ 为偶数时基本解是第 $r-1$ 项渐近分数，$r$ 为奇数时是第 $2r-1$ 项。

### $D = 2$ 的例子

$\sqrt{2} = [1; \overline{2}]$ 的渐近分数 $1/1$、$3/2$、$7/5$、$17/12$、$41/29$、$99/70$、$\dots$ 中：

$$x^2 - 2y^2 = 1: \quad (x, y) = (3, 2),\ (17, 12),\ (99, 70),\ \dots$$

$$x^2 - 2y^2 = -1: \quad (x, y) = (1, 1),\ (7, 5),\ (41, 29),\ \dots$$

## M03.7 拉马努金的连分数

- **最著名的就是 Rogers–Ramanujan 连分数**（M03.4），出自他与 Rogers 各自独立发现的恒等式。
- 他的三本笔记中有大量连分数条目，多为 q-连分数（分母含 $q$ 的幂），与 q-级数（M07）、模方程（M06）交织；Berndt 在五卷本中逐条给出证明或文献指引。
- Andrews–Berndt《Lost Notebook》Part I（2005）以**连分数与 q-级数**为重点，共讨论 442 条。
- 推广：Rogers–Ramanujan 连分数有 Göllnitz–Gordon 型推广（分拆恒等式一侧的对应物），见 M05、M13 的延伸阅读。
