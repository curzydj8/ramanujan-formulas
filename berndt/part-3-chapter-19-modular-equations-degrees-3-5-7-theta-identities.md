# Part III，Chapter 19——Modular Equations of Degrees 3, 5, and 7 and Associated Theta-Function Identities（3、5、7 次模方程与相关 theta 函数恒等式）

出处：Bruce C. Berndt，《Ramanujan's Notebooks》，Part III，Springer，1991，Ch. 19，书页 220–324。

本章是 Part III 的第四章、Berndt 五卷的第 19 章：拉马努金在此先推出一批 theta 函数恒等式，再由此建立 3、5、7 次模方程——Berndt 在章首导言（p. 220）中称本章“in several ways, this is a remarkable chapter”：结果极有趣且常难证，拉马努金的方法至今未能辨明，书中给出的许多证明与拉马努金本人的方法显然不同；拉马努金一生只发表过一篇讨论模方程的论文。模方程理论始于 Legendre 与 Jacobi，Cayley 与 Enneper 的书为入门文献；但拉马努金的发展远比前人丰富，本章多数模方程不见于别处文献。本章共 **19 条编号 Entry（Entry 1–19，无缺号）**，另含定理 12.1、引理、(12.32) 与各节推论、例题 125 个分体标题（见“本章结构”表后的计数说明）。

## 背景与记号

- 全章默认 $|q| < 1$。拉马努金常把级数的前几项显式写出而不写紧凑的求和记号；下文照录其显式前几项，并在说明中给出一般项的规律。
- theta 函数（Ch. 16 Entry 22）：$\varphi(q) := f(q,q) = \sum_{n=-\infty}^{\infty}q^{n^2}$，$\psi(q) := f(q,q^3) = \sum_{n=0}^{\infty}q^{n(n+1)/2}$，$f(a,b) := \sum_{n=-\infty}^{\infty}a^{n(n+1)/2}b^{n(n-1)/2}$，$f(-q) := f(-q,-q^2) = (q;q)_{\infty}$，$\chi(q) := (-q;q^2)_{\infty}$。另有一单变量记号 $f(q)$（Ch. 16 文件已数值核对确认）：书中 $f(q)$ 指 $f(q,-q^2)$，即 $f(q) = (-q;q^2)_{\infty}(q^2;q^2)_{\infty}$；本章 Entry 9(ii) 与 Entry 12 引理中的 $f(q)$ 皆按此义理解。

$$q^{1/8}\psi(q)/\varphi(q) = q^{1/8}/(1 + q/(1+q + q^2/(1+q^2 + q^3/(1+q^3 + \cdots)))).$$

$$v = q^{1/2}f(-q,-q^7)/f(-q^3,-q^5),$$

## Entry 5

**陈述。** $\beta$ 为 $\alpha$ 的 3 次模，$m$ 为 3 次乘子。则下列为 3 次模方程、乘子公式与恒等式：

**(i)**

$$(\alpha^3/\beta)^{1/8} - ((1-\alpha)^3/(1-\beta))^{1/8} = 1 = ((1-\beta)^3/(1-\alpha))^{1/8} - (\beta^3/\alpha)^{1/8}.$$

**(ii)**

$$(\alpha\beta)^{1/4} + \{(1-\alpha)(1-\beta)\}^{1/4} = 1.$$

**(iii)**

$$m = 1 + 2(\beta^3/\alpha)^{1/8};\quad 3/m = 1 + 2((1-\alpha)^3/(1-\beta))^{1/8}.$$

**(iv)**

$$m^2\{(\alpha^3/\beta)^{1/8} - \alpha\} = (\alpha^3/\beta)^{1/8} - \beta.$$

**(v)**

$$m = \{1 - 2(\beta^3(1-\beta)^3/(\alpha(1-\alpha)))^{1/8}\}/\{1 - 2(\alpha\beta)^{1/4}\} = \{1 + 4(\beta^3(1-\beta)^3/(\alpha(1-\alpha)))^{1/8}\}^{1/2},$$

$$3/m = \{2(\alpha^3(1-\alpha)^3/(\beta(1-\beta)))^{1/8} - 1\}/\{1 - 2(\alpha\beta)^{1/4}\} = \{1 + 4(\alpha^3(1-\alpha)^3/(\beta(1-\beta)))^{1/8}\}^{1/2}.$$

**(vi)** 参数化：若

$$\alpha = p((2+p)/(1+2p))^3,$$

则

$$\beta = p^3((2+p)/(1+2p)),\quad 1-\alpha = (1+p)((1-p)/(1+2p))^3,\quad 1-\beta = (1+p)^3((1-p)/(1+2p)).$$

**(vii)**

$$m^2 = (\beta/\alpha)^{1/2} + ((1-\beta)/(1-\alpha))^{1/2} - (\beta(1-\beta)/(\alpha(1-\alpha)))^{1/2},$$

$$9/m^2 = (\alpha/\beta)^{1/2} + ((1-\alpha)/(1-\beta))^{1/2} - (\alpha(1-\alpha)/(\beta(1-\beta)))^{1/2}.$$

**(viii)**

- Entry 2(ii) 第一式：书中印为 $f(-q^8,-q^{12})$，幂级数比较（左端 $q^{12}$ 系数 $0$、右端 $-1$）、乘积展开（左端含 $(q^{13};q^{21})_{\infty}$、右端按印文为 $(q^{12};q^{21})_{\infty}$）与指数和规律（本条其余四式皆为 15 或 21）三处一致表明应为 $f(-q^8,-q^{13})$；订正后数值复核差 $0$；待查 Berndt 勘误。
- Entry 13(xiv) 的 $P$ 指数：书中印为 $\{16\alpha\beta(1-\alpha)(1-\beta)\}^{1/2}$，证明由 (13.8) 推出 $4P^2 = (m-1)(5/m-1)$，而 (13.8) 为 $\{16\alpha\beta(1-\alpha)(1-\beta)\}^{1/6} = \frac14(m-1)(5/m-1)$，故 $P$ 的指数应为 $1/12$；按印文 $1/2$ 计，$p = 0.05$ 时左端与右端差约 $2866$，按 $1/12$ 计差 $\le 1.0\times 10^{-30}$；待查 Berndt 勘误。
- Entry 19(xi) 的适用范围：书中印为 $\cos(2\mu) = (2\cos\nu-1)(4\cos\nu-3)^{1/2}$，证明只推出平方关系 $\cos^2(2\mu) = (2\cos\nu-1)^2(4\cos\nu-3)$，取平方根时未论证符号；平方形式在 $t = 0.3$、$0.45$、$0.6$、$0.8$ 处差 $0$，印文形式在 $t = 0.6$（左端 $-0.104$、右端 $+0.104$）、$0.8$（左端 $-0.408$、右端 $+0.408$）处符号相反；正确一般形式为 $\cos(2\mu) = \pm(2\cos\nu-1)(4\cos\nu-3)^{1/2}$，符号 $= \mathrm{sign}(\cos 2\mu)$；待查 Berndt 勘误与文献。
- Entry 11(iv)(11.3) 在 $q = 0.5$ 处的 30 位差 $7.8\times 10^{-23}$：已定位为纯抵消噪声（$5+\mu^{1/5}-\nu^{1/5}\approx 1.8\times 10^{-13}$，由两个约 $8.09$ 的量相减得到），50 位重算差 $1.2\times 10^{-42}$；公式本身无误，此处仅记录数值复核的精度细节。
- Entry 18(ii) 的 $u$、$v$、$w$：陈述只说“如 (i) 所给”，未明言变量；按 (i) 的函数在陈述变量 $q$ 处理解时数值不符（$q = 0.5$ 时差 $0.29$），按证明 (18.41)(18.42) 的变换变量 $Q$（$7\cdot\mathrm{Log}(1/Q)\cdot\mathrm{Log}(1/q) = 4\pi^2$）理解时差 $\le 7.9\times 10^{-31}$；待查 Berndt 勘误或 Ch. 20 的对应表述。
- Entry 13(i)(ii) 与 Entry 15(ii)：书中注明等价于 theta 恒等式但未直接构造证明（p. 284–285、p. 293）；直接证明的有无待查文献。
